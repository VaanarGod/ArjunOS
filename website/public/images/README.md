# ArjunOS website images

Drop these files into this folder with exactly these names. The website
shows a "drop your screenshot here" placeholder until each file exists,
so nothing breaks in the meantime.

| Filename | Suggested content |
|---|---|
| screenshot-chat.png        | Main chat interface, streaming from a local model |
| screenshot-crew.png        | Crew workspace: boss + worker panels + browser pane |
| screenshot-browser.png     | Built-in browser with an open page being read |
| screenshot-memory.png      | Memory screen (SQLite FTS5 list, undo button) |
| screenshot-profile.png     | Settings → Profile (name, answer style, token meter) |
| screenshot-settings.png    | Settings page overview (left list, right page) |
| screenshot-floating.png    | Floating assistant / pet above other windows |

Screenshots should be 16:10 (e.g. 1600×1000) PNGs for best results.
